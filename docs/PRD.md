# JobSmart PRD (Product Requirements Document)

## 1. 產品概述

### 1.1 產品名稱
**JobSmart** - 智慧求職管理平台

### 1.2 產品願景
打造一站式 AI 驅動的求職管理工具，幫助求職者有效追蹤職缺、優化履歷、準備面試，並透過數據分析做出更明智的職涯決策。

### 1.3 目標用戶
- 主要市場：台灣求職者
- 使用語言：繁體中文
- 用戶類型：應屆畢業生、轉職者、職涯發展中的專業人士

### 1.4 核心價值主張
1. **效率提升**：統一管理所有求職活動，減少資訊分散
2. **AI 賦能**：自動化履歷優化、JD 分析、面試練習評分
3. **數據驅動**：追蹤應徵進度、分析回覆率、評估公司評價
4. **個人化匹配**：基於個人價值觀推薦適合的職位

## 2. 功能需求

### 2.1 核心功能模組

#### 📋 職缺追蹤 (Job Application Tracking)
| 功能 | 描述 | 優先級 |
|------|------|--------|
| Kanban 看板 | 拖拉式管理職缺狀態 (願望清單→編輯中→已投遞→面試1-8→Offer) | P0 |
| 職缺新增 | 輸入公司、職位、JD URL/內容 | P0 |
| JD 自動擷取 | 從 URL 自動抓取並解析 JD 內容 | P1 |
| 關鍵字提取 | AI 分析 JD，提取技能要求、職責、福利 | P1 |
| 評分系統 | 對每個職缺評分 (快樂度、薪資匹配、同事、壓力) | P2 |
| 薪資計算 | 含通勤、房租、餐費等實際成本計算 | P2 |

#### 📄 履歷管理 (Resume Management)
| 功能 | 描述 | 優先級 |
|------|------|--------|
| 多版本履歷 | 針對不同職位類型建立多份履歷 | P0 |
| 富文本編輯器 | TipTap 編輯器，支援格式化、連結、清單 | P0 |
| ATS 評分 | 自動計算履歷 ATS 友善程度 (0-100) | P1 |
| 關鍵字匹配 | 分析履歷與 JD 的關鍵字匹配程度 | P1 |
| AI 優化建議 | GPT-4 提供改進建議、強動詞推薦 | P1 |
| PDF 匯出 | 將履歷匯出為 PDF 格式 | P1 |
| 客製化履歷 | 針對特定 JD 自動生成客製版本 | P2 |

#### 💼 LinkedIn 優化
| 功能 | 描述 | 優先級 |
|------|------|--------|
| 內容生成 | AI 生成 Headline、About、Experience 描述 | P1 |
| 熱門技能分析 | 從追蹤職缺中提取高頻技能 | P2 |
| STAR 方法優化 | 將經歷改寫為 STAR 格式 | P2 |

#### 🎤 面試練習 (Interview Practice)
| 功能 | 描述 | 優先級 |
|------|------|--------|
| 題庫瀏覽 | 分類題庫 (行為、技術、情境、文化適配等) | P1 |
| 語音錄製 | 錄製回答並自動轉文字 (Whisper API) | P1 |
| AI 評分 | GPT-4 評估回答，給予分數和改進建議 | P1 |
| 練習歷史 | 追蹤練習記錄和進步情況 | P2 |

#### 🏢 公司研究 (Company Research)
| 功能 | 描述 | 優先級 |
|------|------|--------|
| 多源爬蟲 | 從 Dcard、PTT、Qollie、Medium 抓取評價 | P1 |
| 情感分析 | AI 分析評價正負面傾向 | P1 |
| 評分聚合 | 綜合多維度評分 (快樂度、薪資、同事、壓力) | P2 |

#### 🎯 價值觀探索 (Values Assessment)
| 功能 | 描述 | 優先級 |
|------|------|--------|
| 價值卡排序 | 20 張價值卡拖拉排序 | P2 |
| 職位匹配 | 基於價值觀計算職位適配度 | P2 |

#### 📊 儀表板 (Dashboard)
| 功能 | 描述 | 優先級 |
|------|------|--------|

## 3. 非功能需求

### 3.1 效能需求
- 頁面首次載入 < 3 秒
- API 回應時間 < 500ms (非 AI 請求)
- AI 分析回應 < 10 秒

### 3.2 安全需求
- Turso RLS 確保用戶資料隔離
- NextAuth.js 身份驗證
- 敏感資料加密儲存

### 3.3 可用性需求
- 響應式設計，支援桌面和行動裝置
- 中文介面
- 拖拉操作支援觸控設備

### 3.4 擴展性需求
- 訂閱分層：Free / Pro / Enterprise
- AI 額度管理和用量追蹤
- 支援未來新增爬蟲來源

## 4. 用戶故事

### 求職者小明的一天
1. **早上**：登入 Dashboard 查看本週進度，發現還差 3 份履歷投遞
2. **中午**：看到有興趣的職缺，用「新增追蹤」加入 Kanban，系統自動解析 JD
3. **下午**：為該職缺生成客製化履歷，查看 ATS 分數並優化
4. **晚上**：用面試練習功能回答 3 道行為題，獲得 AI 回饋
5. **睡前**：查看該公司在 Dcard/PTT 的評價，決定是否投遞
